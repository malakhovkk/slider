Интерактивная презентация из 3 слайдов
======================================

Запуск:
1. Распакуйте архив.
2. Откройте index.html в браузере.
   Для локальной разработки можно запустить: python -m http.server 8000
   и открыть http://localhost:8000

Структура:
- index.html
- styles.css
- script.js
- assets/slide-1.jpg ... slide-3.jpg

Важно:
Картинки в assets извлечены из приложенного скриншота и служат визуальными
заглушками. Для production замените их оригинальными изображениями слайдов
в высоком разрешении, сохранив имена файлов или обновив пути в index.html.

Поведение:
- три вертикальных scroll-сегмента;
- активный слайд меняется по центру viewport;
- desktop: вращающееся боковое колесо с кликабельными пунктами;
- mobile: колесо скрыто, остаётся свайп/обычный скролл;
- поддерживается prefers-reduced-motion.
